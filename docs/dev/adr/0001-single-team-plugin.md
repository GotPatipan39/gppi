# gppi เป็น plugin ก้อนเดียว ไม่แยกตามโดเมน

gppi มาแทน mskills เป็น plugin ตัวเดียวที่มีทุก skill, `rules.md`, agent `safety-reviewer` และตัวกันคำสั่ง ไม่ได้แยกเป็น `gppi-core`, `gppi-ros2`, `gppi-modbus` ให้แต่ละคนเลือกลง
เหตุผล: ทีมยังเล็ก คนส่วนใหญ่ทำหลายงานปนกัน (ROS2 + Modbus + UI ในโปรเจกต์เดียว) และกฎความปลอดภัยต้องติดไปกับทุกเครื่อง ถ้าแยก plugin คนที่ลงแค่ `gppi-vision` จะไม่ได้ตัวกันคำสั่งเครื่องจักร
แลกกับ: ทุกคนโหลด skill ที่ไม่ได้ใช้ (ไม่หนักเพราะ skill โหลดเนื้อหาเมื่อถูกเรียกเท่านั้น)

## Considered Options
- **marketplace หลาย plugin** (`gppi-core` + plugin ตามโดเมน, ใช้ `dependencies` ให้ทุกตัวพึ่ง core): เหมาะเมื่อทีมโตจนแต่ละคนทำงานเฉพาะทาง — เปลี่ยนเป็นแบบนี้ทีหลังได้ แต่ชื่อ skill จะเปลี่ยนจาก `gppi:modbus` เป็น `gppi-modbus:modbus` ทุกที่ที่อ้างถึงต้องแก้
- **gppi คู่กับ mskills**: กฎและตัวกันจะทำงานซ้ำสองชุด
