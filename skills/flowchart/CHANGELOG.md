# CHANGELOG — flowchart

## 1.1.0 — 2026-10-15
- ตัวตรวจ: เพิ่มการตรวจจากพิกัด — กล่องทับกัน, เส้นวิ่งทับกล่อง, เส้นตัดกัน (เฉพาะเส้นที่มีจุดหัก ไม่เดาเส้นที่ draw.io เดินเอง), id 0/1 ถูกใช้ซ้ำ, เส้นไม่มี mxGeometry, กล่องไม่มีขนาด — จับเส้นตัดกันจริงในตัวอย่างเดิมได้ (แก้แล้ว); ทดสอบกล่องทับ/เส้นทับกล่อง/id สงวน/เส้นไม่มี geometry ด้วยไฟล์ที่ตั้งใจทำผิด
- ตัวตรวจตรวจเส้นตรงแนวนอน/ตั้งที่ไม่มีจุดหักด้วย (ลองใช้ skill กับ poll loop ของ Modbus แล้วเจอเส้นตัดกันที่ตัวตรวจไม่จับ — ตอนนี้จับได้ และไม่มี warning ปลอมเพิ่มในไฟล์ตัวอย่างอื่น); เส้นที่ใส่ `jumpStyle` ไม่ถูกเตือนเรื่องตัดกัน
- เพิ่มตัวอย่าง `examples/modbus-poll-loop.drawio` — CI ตรวจทุกไฟล์ใน `examples/`
- การวาง: เกิน ~15 กล่องให้ draw.io จัดด้วย `--layout verticalFlow`, ร่างเร็วด้วย Mermaid → `.drawio` (draw.io ≥ 30 — ทดสอบกับ 31.7 และภาษาไทยแล้ว); ดูรูปแก้ไม่เกิน 2 รอบ; รูปสำหรับดูเองไม่ใส่ `-e`
- แนวคิดจาก Agents365-ai/drawio-skill @ 5727082 (MIT) — ไม่ได้ copy โค้ด (ของเขาเป็น Python) เหตุผลที่ไม่รับทั้งตัวอยู่ใน docs/MAINTAINING.md

## 1.0.0 — 2026-10-15
- เวอร์ชันแรก (เขียนเอง ไม่ได้มาจากภายนอก): ผู้ใช้สรุป logic เป็น flowchart ใน draw.io ก่อนเขียนโค้ดเสมอ — logic ที่มีลำดับ/เงื่อนไขต้องมี flowchart `docs/flowcharts/<ชื่อ>.drawio` ที่ผู้ใช้ OK ก่อนเขียนโค้ด และแก้ logic ต้องแก้ flowchart ใน commit เดียวกัน (ผู้ใช้เลือกทั้งสามข้อ)
- เนื้อหาที่ logic คุมเครื่องต้องมี: ทุกการรอมี timeout, ทาง fault/STOP, ไม่เดินเองหลัง reset, ค่า hardware จาก CLAUDE.md
- `tools/check_drawio.mjs` (node ไม่มี dependency): ตรวจทางแยกที่ขาดทางออก/ไม่มีป้าย, เส้นลอย, id ซ้ำ, กล่องค้าง; `--outline` แปลง flowchart เป็นข้อความ; อ่านไฟล์บีบอัดและ `.drawio.svg` ได้ — ทดสอบกับไฟล์ที่ตั้งใจทำผิด 5 แบบ (จับได้ทุกแบบ: 4 เป็น error, กล่องไม่มีทางออกเป็น warning) และไฟล์บีบอัดที่ draw.io 31.7 เปิดได้
- ตัวอย่าง `examples/clamp-press-cycle.drawio` ผ่านตัวตรวจ และ export เป็น PNG ด้วย draw.io 31.7 ดูแล้วว่าไม่มีอะไรทับกัน
