## Register / interface map
<ชี้ไปเอกสารหรือ flowchart ที่มีแผง REGISTER OWNERSHIP ถ้ามี — แล้วสรุปเฉพาะที่ต้องรู้ก่อนแก้โค้ด>

| register | ใครเขียน | ใครอ่าน | ความหมาย / ค่า | สถานะ |
|---|---|---|---|---|
| `<D100>` | PLC | เรา | <1 = ชิ้นงานมาถึง> | ✅ <วันที่> |
| `<D102>` | เรา | PLC | <2 = OK, 99 = NG> | ⚠️ |

- **register ที่สองฝั่งเขียนร่วมกัน = เสี่ยง race** — บอกว่าใครเคลียร์ค่าและเพราะอะไร
