# หน้าจอ HMI คุมเครื่องจักร

## โครงหน้าจอมาตรฐาน
```
┌──────────────────────────────────────────────────────────────┐
│ ชื่อเครื่อง │ MODE: AUTO │ สถานะ: RUNNING │ ● PLC ok │ 14:32 │ ← header (ติดบนเสมอ)
├──────────────────────────────────────────────────────────────┤
│ ⚠ ALARM ล่าสุดที่ยังไม่ ack (ถ้ามี) ............ [ดูทั้งหมด] │ ← alarm banner
├───────────────────────────────────────┬──────────────────────┤
│                                       │  ปุ่มสั่งงานหลัก      │
│   ภาพรวมกระบวนการ / ค่าหลัก           │  [START] [STOP]      │
│   (ค่าที่สำคัญ 3–6 ตัว + สถานะ)        │  [MODE ▸]            │
│                                       │  ข้อความ interlock   │
├───────────────────────────────────────┴──────────────────────┤
│ [หน้าหลัก] [Manual] [Alarm] [Trend] [ตั้งค่า🔒]                │ ← navigation
└──────────────────────────────────────────────────────────────┘
```
- header และ alarm banner อยู่ทุกหน้า
- ปุ่มสั่งงานอยู่ตำแหน่งเดิมทุกหน้า (operator จำตำแหน่ง ไม่ได้อ่าน)
- หน้าตั้งค่าแยกออกไป และต้องมีสิทธิ์ (ดู config.md)

## ลำดับชั้นของหน้าจอ (ISA-101)
| ระดับ | หน้าจอ | ใช้ |
|---|---|---|
| 1 | ภาพรวมทั้งระบบ | ดูว่าส่วนไหนผิดปกติ |
| 2 | หน่วย/เครื่องเดียว | สั่งงานปกติ |
| 3 | รายละเอียดอุปกรณ์ | manual, ปรับแต่ง |
| 4 | วินิจฉัย | ช่าง maintenance (I/O, ค่า raw, สถานะการสื่อสาร) |
กด drill-down จากระดับบนลงล่างได้ และมีปุ่มกลับเสมอ

## Mode
- แสดง mode ปัจจุบันตัวใหญ่ใน header ตลอด (AUTO / MANUAL / MAINTENANCE)
- เปลี่ยน mode ต้องยืนยัน และบอกผล เช่น "เปลี่ยนเป็น MANUAL: เครื่องจะหยุดรอบอัตโนมัติหลังจบรอบนี้"
- ปุ่ม manual/jog ใช้ได้เฉพาะใน MANUAL — ใน AUTO ให้ซ่อนหรือปิดพร้อมบอกเหตุผล

## ปุ่มสั่งงาน
| ประเภท | พฤติกรรม |
|---|---|
| START / RUN | ยืนยัน 2 ขั้นถ้าเครื่องจะขยับเองต่อเนื่อง, ปิดเมื่อ interlock ไม่ครบ |
| STOP | กดครั้งเดียวทำงานทันที ไม่ต้องยืนยัน, ใหญ่และหาเจอง่าย (แต่ไม่ใช่ E-stop) |
| JOG / MANUAL MOVE | **hold-to-run**: pointerdown = เริ่ม, pointerup / pointerleave / pointercancel / หลุด connection / แท็บถูกซ่อน = หยุด และส่ง heartbeat ระหว่างกดค้าง เพื่อให้ฝั่งเครื่องหยุดเองถ้า heartbeat หาย |
| RESET ALARM | ยืนยัน, ใช้ได้เฉพาะเมื่อต้นเหตุหายแล้ว |
- ระหว่างรอผลแสดง "กำลังส่ง…" และล็อกปุ่มกันกดซ้ำ
- สถานะปุ่มต้องมาจากค่าที่อ่านกลับ (เช่น ปุ่ม RUN ติดเมื่อ PLC ยืนยันว่ากำลังเดิน)

## Interlock / เงื่อนไขพร้อมทำงาน
แสดงรายการเงื่อนไขพร้อมสถานะ เมื่อปุ่มถูกปิด:
```
START ใช้ไม่ได้:
  ✓ ประตูปิด
  ✗ แรงดันลม 3.8 bar (ต้อง ≥ 5.0)
  ✓ ไม่มี alarm ค้าง
```

## Alarm
- ระดับ: วิกฤต (แดง) / สูง (ส้ม) / ปานกลาง (เหลือง) / แจ้งเตือน (ฟ้า) — ไม่เกิน 4 ระดับ
- แต่ละ alarm มี: เวลาเกิด, ข้อความ (อะไรเกิด + ต้องทำอะไร), ค่าตอนเกิด, สถานะ (active / ack / หายแล้ว)
- alarm ที่ยัง active และยังไม่ ack = กระพริบช้าๆ (≤ 1 ครั้ง/วินาที) หลัง ack = ติดค้างไม่กระพริบ
- ห้ามมี alarm ที่เกิดบ่อยจนคนกด ack อัตโนมัติ (alarm flood) — ถ้ามี ให้แจ้งผู้ใช้ว่าควรแก้ที่ต้นเหตุหรือปรับเกณฑ์
- เสียงเตือน (ถ้ามี) เฉพาะระดับวิกฤต/สูง และมีปุ่มปิดเสียงแยกจากปุ่ม ack

## สถานะอุปกรณ์ (มอเตอร์, วาล์ว)
| สถานะ | รูปแบบ |
|---|---|
| หยุด (ปกติ) | outline เทา + ข้อความ "หยุด" |
| เดิน (ปกติ) | เติมเทาเข้ม + ข้อความ "เดิน" |
| ผิดปกติ/fault | สี alarm + ไอคอน + ข้อความ |
| ไม่ทราบ (ไม่มีข้อมูล) | ลายขีด/จาง + "?" |
