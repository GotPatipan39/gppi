# Dashboard ดูข้อมูล

## วางลำดับตามคำถามของคนดู
1. **บนสุด: ตอนนี้ปกติไหม** — KPI 3–6 ตัว (ค่าปัจจุบัน + สถานะเทียบเกณฑ์)
2. **กลาง: แนวโน้ม** — trend ของค่าหลักในช่วงเวลาที่เลือก
3. **ล่าง: รายละเอียด** — ตาราง, ค่ารายอุปกรณ์, ประวัติ alarm

## KPI tile
```
┌─────────────────────┐
│ กำลังไฟรวม          │  ← ชื่อสั้น
│ 42.7 kW             │  ← ค่าใหญ่ + หน่วย (tabular-nums)
│ ▲ 3.1 จากชั่วโมงก่อน │  ← เทียบกับอะไร (ระบุให้ชัด)
│ อัปเดต 14:32:05     │  ← หรือแสดงเฉพาะเมื่อ stale
└─────────────────────┘
```
- ค่าปกติ = สีกลาง, เกินเกณฑ์ = สี alarm ตามระดับ **พร้อมข้อความ** ("สูงกว่าปกติ")
- เกณฑ์ (threshold) ต้องมาจากผู้ใช้/มาตรฐานของงาน ห้ามตั้งเอง

## Trend / กราฟเส้น
- ช่วงเวลาเริ่มต้นให้ตรงกับงาน (เฝ้าดู: 1 ชม. / รายงาน: 24 ชม. หรือ 7 วัน) และมีปุ่มเลือกช่วงเร็ว
- แสดงเส้นเกณฑ์ (threshold band) เป็นพื้นจางๆ ไม่ใช่เส้นแดงหนา
- แกน Y: ตั้งช่วงตามช่วงค่าจริงของกระบวนการ ไม่ auto-scale จนเห็น noise เป็นคลื่นใหญ่ (แต่ค่ากระแส/พลังงานที่เริ่มจาก 0 ได้ ให้เริ่มที่ 0)
- ไม่เกิน 4–5 เส้นต่อกราฟ, ค่าที่หน่วยต่างกันแยกกราฟ (หลีกเลี่ยงแกน Y สองข้าง)
- ข้อมูลขาดช่วง → เว้นช่องว่าง ห้ามลากเส้นเชื่อม (Grafana: `Connect null values: Never` หรือกำหนด threshold)
- เวลาใช้ timezone ท้องถิ่นของโรงงาน และ format 24 ชม.

## จอใหญ่ห้องควบคุม (wall display)
- ไม่มีการคลิก → ไม่ใส่ปุ่ม, tooltip, dropdown
- ตัวอักษรใหญ่ (≥ 32 px ค่าหลัก), contrast สูง, พื้นเข้มลดแสงจ้า
- auto-refresh และแสดงเวลาอัปเดตล่าสุดมุมจอ
- ถ้าวนหลายหน้า (playlist) ให้แต่ละหน้าค้าง ≥ 15–30 วินาที และหน้าที่มี alarm ควรค้างไว้

## Tablet / มือถือ
- เรียงเป็นคอลัมน์เดียว KPI ก่อน กราฟทีหลัง
- กราฟเล็กลงได้ แต่ตัวเลขต้องอ่านได้
- อย่าพึ่ง hover (ไม่มีบน touch)

## ข้อมูลพลังงาน / smart meter
- แยก "ค่าทันที" (kW, V, A) กับ "ค่าสะสม" (kWh) — ค่าสะสมแสดงเป็นผลต่างรายช่วง (kWh ต่อชั่วโมง/วัน) จะมีประโยชน์กว่าเลขมิเตอร์
- 3 เฟส: แสดง L1/L2/L3 คู่กันเพื่อเห็นความไม่สมดุล
