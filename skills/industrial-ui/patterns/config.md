# หน้าตั้งค่า parameter / config / สูตรการผลิต

ค่าที่ตั้งผิดทำให้เครื่องเสียหายได้ — หน้านี้เน้น "ป้องกันความผิดพลาด" มากกว่าความสวย

## การเข้าถึง
- แยกจากหน้าใช้งานปกติ และต้อง login/รหัส (อย่างน้อยแยก operator กับ engineer)
- แสดงชัดว่าใคร login อยู่ และ auto-logout เมื่อไม่ใช้งาน
- ถ้าโปรเจกต์ยังไม่มีระบบสิทธิ์ ให้ถามผู้ใช้ก่อนว่าจะใช้วิธีไหน ห้ามทำหน้าตั้งค่าที่เปิดให้ทุกคนแก้ได้โดยไม่บอก

## แต่ละช่อง
```
ความเร็วสูงสุด        [ 0.30 ] m/s      ช่วง 0.05–0.80   ค่าเริ่มต้น 0.30
                       ค่าปัจจุบันในเครื่อง: 0.30
```
- ชื่อที่คนเข้าใจ + หน่วย + ช่วงที่อนุญาต + ค่าเริ่มต้น + **ค่าที่อุปกรณ์ใช้อยู่จริง** (อ่านกลับ)
- ตรวจช่วงทันทีที่พิมพ์ (ขอบแดง + ข้อความ "ต้องอยู่ระหว่าง 0.05–0.80") ก่อนกดบันทึก
- ช่วงที่อนุญาตต้องมาจากผู้ใช้/สเปกอุปกรณ์ ห้ามตั้งเอง
- touch panel: ใช้ปุ่ม +/− หรือ numeric keypad บนจอ ไม่ต้องพึ่ง keyboard
- จัดกลุ่มตามหน้าที่ (การเคลื่อนที่ / ความปลอดภัย / การสื่อสาร) ไม่ใช่ตามลำดับ address

## บันทึกค่า
1. แก้ได้หลายช่อง → ช่องที่แก้มีเครื่องหมาย "แก้แล้ว"
2. กด "ตรวจสอบ" → แสดงตาราง **ก่อน → หลัง** เฉพาะค่าที่เปลี่ยน
3. ยืนยัน → ส่งไปอุปกรณ์
4. **อ่านกลับ** แล้วแสดงผลรายช่อง: ✓ สำเร็จ / ✗ ไม่ตรง (ค่าที่อุปกรณ์ตอบกลับ)
5. บันทึก log: ใคร, เมื่อไร, ค่าเดิม → ค่าใหม่

- มีปุ่ม "ยกเลิกการแก้ไข" และ "คืนค่าเริ่มต้น" (ยืนยันก่อน)
- ค่าที่ห้ามแก้ขณะเครื่องเดิน → ปิดช่องพร้อมบอกเหตุผล
- export / import ชุดค่า (สูตร) เป็นไฟล์ JSON เพื่อสำรอง และเทียบความต่างก่อน import

## สูตรการผลิต (recipe)
- รายการสูตร + ปุ่มโหลด/บันทึกเป็น/ลบ
- โหลดสูตร = แสดงความต่างจากค่าปัจจุบันก่อน แล้วค่อยยืนยัน
- แสดงชัดว่าสูตรไหนกำลังใช้อยู่ในเครื่อง
