# WitMotion JY-ME02-485 (absolute rotary encoder, RS-485, Modbus RTU)

สัญลักษณ์: ✅ = ผู้ใช้ยืนยันจากงานจริงแล้ว, ⚠️ = ต้องยืนยัน, ❓ = ยังไม่รู้ ให้ถามผู้ใช้

| รายการ | ค่า |
|---|---|
| ความละเอียด | ✅ 18-bit |
| Slave ID ของตัวที่ใช้อยู่ | ✅ 80 (0x50) — ไม่ใช่ค่าเริ่มต้นจากโรงงาน |
| Baud / parity | ❓ |
| Function code อ่าน | ✅ FC03 |

## Register (0-based, ✅ ยืนยันแล้ว)
| address | ค่า |
|---|---|
| 2 | จำนวนรอบ (rotations) |
| 17 | มุม (angle) |
| 20 | อุณหภูมิ |

- ✅ ค่า raw ต้องหารด้วย scale ก่อนใช้ (ใน Node-RED ทำด้วย function node) — ❓ ค่า scale ที่แน่นอนของมุม ให้ถามผู้ใช้หรือดูจาก flow ที่มีอยู่
- ⚠️ ถ้ามีหลายตัวบนบัสเดียว ต้องเปลี่ยน slave ID ให้ไม่ซ้ำก่อน (ทำผ่านการเขียน register ตามคู่มือ WitMotion — ยืนยันกับคู่มือก่อน เพราะเขียนผิดแล้วอาจติดต่อตัวนั้นไม่ได้)

## ทดสอบเร็ว
ถามผู้ใช้ก่อนรัน — เปิด serial port ที่ระบบใช้อยู่จะชนกับ master ตัวเดิมบน bus (ดู SKILL.md หัวข้อเครื่องมือ debug)
```bash
mbpoll -m rtu -b <baud> -P none -a 80 -0 -r 17 -c 1 /dev/ttyUSB0
```
