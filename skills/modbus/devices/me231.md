# ME231 three-phase smart meter (Rogowski coil, Modbus RTU)

สัญลักษณ์: ✅ = ผู้ใช้ยืนยันจากงานจริงแล้ว, ❓ = ยังไม่รู้ ให้ถามผู้ใช้

| รายการ | ค่า |
|---|---|
| Protocol | ✅ Modbus RTU |
| Data type | ✅ Float32, **big-endian (ABCD)** |
| Register เริ่มต้น | ✅ 1000 |
| ลำดับค่าแต่ละตัวหลัง 1000 (V, A, kW, kWh ...) | ❓ ดูจาก flow Node-RED เดิมหรือ datasheet |
| Slave ID / baud | ❓ |

- ค่า Float32 ใช้ 2 register ต่อค่า → ค่าที่ k อยู่ที่ `1000 + 2k`
- อ่านเป็นบล็อกเดียวทั้งชุด แล้วถอดทีละ 4 byte (`readFloatBE` ใน Node-RED, `DATATYPE.FLOAT32` ใน pymodbus)
- ใช้กับ pipeline Node-RED → PostgreSQL → Grafana ได้ (ดู [../clients/node-red.md](../clients/node-red.md))
